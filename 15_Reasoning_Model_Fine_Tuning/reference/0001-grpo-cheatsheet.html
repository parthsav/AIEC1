Reasoning Model Fine-Tuning Cheat Sheet

The compressed version of Lessons 0000–0006. Use this mid-notebook when you need a fast reminder, not a first explanation — for that, go back to the lessons.

The loop, in one line

prompt → sample group of 8 completions → score each with rewards
       → compare to group average (advantage) → nudge policy (KL-limited) → repeat

Glossary

TermCompressed definition
LoRAFreeze the big weight matrix W; train two small matrices A, B so the model uses W + BA. Only A/B get gradients.
Rank (r)How "thin" A and B are. Higher = more trainable capacity, more VRAM/time. This notebook: 64.
QuantizationStoring numbers with fewer bits (rounding). QLoRA = LoRA + 4-bit quantized base weights.
PolicyThe model's current tendency to generate certain outputs — literally its current weights, not a rulebook.
RewardA raw score for one completion, from a reward function.
AdvantageReward compared to a baseline (expectation). What actually drives the update — not the raw reward.
Critic / value networkA second network PPO trains to estimate the baseline. GRPO replaces this with the group's own average.
GRPOGroup Relative Policy Optimization — sample a group per prompt, use the group's mean reward as the baseline, update with a KL penalty. No critic needed.
KL penaltyA "leash" limiting how far one update can move the policy from where it started — keeps training stable.
SFT (supervised fine-tuning)Train by copying shown examples of correct behavior. Needs labeled reasoning traces.
RL (reinforcement learning)Train by scoring attempts and letting the policy improve toward higher scores. Needs only a way to check outcomes.
Verifiable rewardA reward that can be computed by a rule (string/number match) rather than a human or a trained judge — e.g. GSM8K's #### answer.

Key GRPOConfig knobs (Task 6)

ArgumentWhat it controls
num_generationsGroup size GRPO compares within (8). Lower it (e.g. 4) if out of memory.
per_device_train_batch_size × gradient_accumulation_stepsMust be evenly divisible by num_generations — the hard batch-geometry rule.
learning_rateSize of each update step.
warmup_ratioFraction of training spent easing into the full learning rate.

max_grad_normCaps the size of any single update step (separate from the KL penalty).

What to watch during training

Loss goes down in SFT. In GRPO, watch reward instead — expect it flat/noisy for ~100–150 steps, then a sudden climb (the "Aha moment"). No movement early on is normal, not broken.

Before/after (Tasks 8–9)

LoRA never touches the frozen base weights, so one vLLM engine can generate from either: lora_request = None → base model. lora_request = model.load_lora(...) → trained model. model.save_lora(...) writes only the small A/B adapter, not a full checkpoint.
